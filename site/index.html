Every team, re-rated after every match.

A sequential Bayesian model for eight European leagues. Each team carries an attack and a defence rating with its own uncertainty; after each result both move, by more when the model was less sure. Every improvement was written down and committed before its data was looked at, then judged once.

Group B12: Akshara Sree R, Anirudh S Nair, Iniyaa Muthuselvan, Shashank Kannan. Guided by Dr. Sruti S.

Overview

Each team has two numbers: how many goals it tends to score (attack) and how many it tends to let in (defence). The model holds each as a Gaussian belief, a best guess and a spread. Before a match it turns the two teams' ratings and a home advantage into expected goals for each side.

Goals are Poisson, with the Dixon-Coles adjustment for 0-0, 1-0, 0-1 and 1-1, which gives a full scoreline grid and from it home, draw and away. After the final whistle, the gap between goals scored and goals expected nudges each rating; the nudge is bigger when the spread is wide.

      Methods, and what did not work

      How the testing was kept honest

      Data were split by time, never shuffled. Early seasons only warm the ratings up. Every setting was chosen on a development window and a validation window that come before any test data.

      Each test window was scored once, by a script that refuses to run twice: a held-out window running to May 2026, four older seasons no earlier stage had looked at, and the completed 2026-27 matches. Before each one, the rule for passing was committed to the repository.

      Models are compared by log-loss per match with a paired bootstrap interval. A change counts as better only when the whole interval is below zero.

      Every figure on this site is copied from a committed result file. Headline figures carry the id of their entry in results/claims.json, which a checker ties back to its source.

      1. Surprise-driven updating

        Let a surprising result move ratings further. Validation picked the setting that turns it off: validation log-loss with it off, rising to , and as it was turned up. The Bayesian update already reacts more to surprises.

      2. Lineup weighting

      3. Blending with market odds

        Stack the model with pre-match odds. It did not beat the odds on their own: interval [, ] includes zero, so the final model stays odds-free.

      4. Forecasting from the full belief

        Average the forecast over each rating's uncertainty instead of using its centre. It was worse on both development windows; the interval [, ] lies above zero. The spread does its job in learning, not in forecasting.
