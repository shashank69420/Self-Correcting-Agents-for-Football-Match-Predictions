GitHub

Every team, re-rated after every match.

This project forecasts football matches in eight European leagues. Each team has an attack and a defence rating, and the model is never sure of either: it keeps a best guess and a measure of doubt. After every result both ratings move, further when the doubt was large. That is the self-correcting part.

The project was run like an experiment. Each idea was written down and committed before its data was looked at, then judged once, so every result is reported in full.

The project

Problem statement. Given the results so far, give every upcoming match in eight European top divisions a probability for a home win, a draw and an away win, using only what is known an hour before kickoff, and judge those forecasts on matches the model has never been fitted to.

Why it matters

  • Clubs and analysts use team ratings to scout opponents and to tell real change from a lucky run.
  • Media and fan platforms publish win probabilities; honest uncertainty makes them more useful.
  • The gap to the betting market shows how much public information the market already prices.
  • Time-ordered testing and pre-registration carry over to forecasting in demand, health and credit.

Objectives

  • A reproducible data pipeline with a strict time-ordered split and no post-match information.
  • A static Dixon-Coles benchmark and a sequential Bayesian filter for team strength.
  • Two self-correcting extensions: surprise-driven updates and starting line-up values.
  • Better filter settings learned from training data only, accepted by a rule written in advance.
  • Confirmation on unseen seasons and on 2026-27, compared with the closing market.
  • Tested software and fan-facing outputs: ratings with uncertainty and scoreline odds.

Scope

Covered: full-time home, draw and away probabilities and expected goals for the top divisions of England, Spain, Germany, Italy, France, the Netherlands, Portugal and Turkey, using pre-match information only. Market odds serve as a benchmark.

Next steps beyond this scope: in-play prediction, cups and international matches, event-level data such as expected goals, and betting strategy.

Data and preparation

  • Results and odds

    Results, shots on target and bookmaker odds for seasons 2019-20 to 2025-26 from football-data.co.uk, read through the penaltyblog library. Older seasons from the same source confirm the results.

  • Line-ups and values

    Starting line-ups and dated player valuations from the open Transfermarkt dataset, using only each player's last valuation before the match.

  • Cleaning

    Seasons are joined, incomplete rows dropped and every match sorted by kickoff time. Each match becomes a date, two teams, the goals, shots on target and odds.

  • Time-ordered split

    The earliest matches warm the ratings up, later windows tune and validate, and the most recent matches are held out for testing, so the model never sees the future.

Overview

Each team has two numbers: how many goals it tends to score (attack) and how many it tends to let in (defence). The model holds each as a Gaussian belief, a best guess and a spread. Before a match it turns the two teams' ratings and a home advantage into expected goals for each side.

Goals are Poisson, with the Dixon-Coles adjustment for 0-0, 1-0, 0-1 and 1-1, which gives a full scoreline grid and from it home, draw and away. After the final whistle, the gap between goals scored and goals expected nudges each rating; the nudge is bigger when the spread is wide.

      Methods and research milestones

      How the testing was kept honest

      • Split by time

        Data were split by date, never shuffled. Early seasons only warm the ratings up, and every setting was chosen on windows that come before any test data.

      • Rules written first

        Before each test, the rule for passing was committed to the repository, so the verdict could not bend to the result.

      • Scored once

        Each test window was scored by a script that refuses to run twice: a held-out window, older seasons no earlier stage had seen, and the current season.

      • Traced figures

        Models are compared by log-loss with a paired bootstrap interval, and every figure on this site is copied from a committed result file and checked automatically.

      Research milestones

      • Surprise-driven updating

        Letting surprising results move ratings further was tested. The Bayesian update already reacts more to surprises, so the filter handles them on its own.

      • Lineup weighting

        Starting line-up market values showed a clear attack effect. The model stays lineup-free, so it can forecast days before kickoff.

      • Blending with market odds

        The odds already carry their information on their own, so the final model stays independent of the market.

      • Forecasting from the full belief

        The plug-in forecast was confirmed: the spread does its job in learning, and the best guess makes the sharpest forecast.

      Conclusion

      What the project achieved

      A transparent, fully tested forecasting system for eight European leagues. The filter matches a classic static model while updating live. Learned settings (P1) improved forecasts under a rule written in advance, and the gain was confirmed on unseen seasons and on 2026-27. Adding shots on target (P2) improved them further. The result is a lean model that needs only results and shots and closes much of the gap to the betting market.

      Future enhancements

      • Keep the live forecast log running to build a large forward test.
      • Use reserved older seasons to confirm the next model.
      • Feed richer evidence into the update, such as expected goals and big chances.
      • Sharpen the defence signal with goalkeeper and minutes-weighted values.
      • Extend to second divisions and European cups to link the leagues.
